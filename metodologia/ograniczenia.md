# Ograniczenia metody

1. Rodziny PVC, TPO/FPO i EPDM obejmują wiele różnych produktów.
2. Parametry konkretnego produktu nie reprezentują automatycznie całej rodziny.
3. Różne normy badawcze ograniczają bezpośrednią porównywalność.
4. Dokumentacja techniczna może ulegać zmianie.
5. Metodyka nie zastępuje projektu ani dokumentacji producenta.
