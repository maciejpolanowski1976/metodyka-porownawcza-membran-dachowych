# Zasady porównywalności

Dane liczbowe można porównywać bezpośrednio tylko wtedy, gdy:
- dotyczą tej samej właściwości,
- zastosowano tę samą lub równoważną metodę,
- znana jest grubość i konstrukcja membrany,
- warunki badania są porównywalne,
- źródło jednoznacznie identyfikuje produkt.

Jeżeli warunki nie są spełnione, nie stosuje się szacunkowej punktacji.
